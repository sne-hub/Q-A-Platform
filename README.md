# SANRAL Q&A Platform

A Next.js and TypeScript room Q&A app. Visitors give their details first, then ask up to three questions (or stop earlier). Each person only sees their own questions. Admins on `/dashboard` see every question grouped by name, surname, and email.

## Run locally

```bash
npm install
npm run dev
```

- Ask form: [http://localhost:3000](http://localhost:3000)
- Admin dashboard: [http://localhost:3000/dashboard](http://localhost:3000/dashboard)
